마에스트로

개인정보처리방침

시행일 2026년 10월 21일

마에스트로(이하 ‘앱’)는 사용자가 자기 PC 에 설치해 쓰는 업무 대시보드입니다. 앱은 사용자 PC 안에서만 실행되며, 개발자는 사용자 정보를 받거나 보관하는 서버를 운영하지 않습니다.

1. Google 로그인으로 확인하는 정보

  • 앱은 허용된 조직(회사) 계정의 사람만 쓸 수 있도록 Google 로그인을 사용합니다.
  • 요청하는 권한은 openid · email 뿐입니다. 이를 통해 이메일 주소, 이메일 인증 여부, 조직 도메인만 확인합니다.
  • 확인 목적은 ‘허용된 조직 계정인지’ 판단하는 것 하나입니다. Gmail·드라이브·캘린더 등 다른 Google 데이터에는 이 로그인으로 접근하지 않습니다.
  • Google 이 발급한 토큰은 확인 직후 버리고 저장하지 않습니다. 로그인 상태는 사용자 PC 에 서명된 쿠키(이메일 주소 포함, 30일)로만 남습니다.

2. 저장 위치와 전송

  • 앱이 만드는 기록(대화·작업 결과·설정)은 모두 사용자 PC 의 앱 폴더에만 저장됩니다.
  • 개발자에게 전송되거나 제3자에게 제공·판매되지 않습니다. 광고·분석 도구를 쓰지 않습니다.

3. 사용자가 직접 연결하는 외부 서비스

  • AI 엔진(Anthropic Claude, OpenAI ChatGPT)은 사용자가 본인 계정으로 직접 로그인해 씁니다. 사용자가 AI 에게 보낸 내용은 그 회사 서비스로 전송되며, 처리 방식은 각 회사의 정책을 따릅니다.
  • Google 드라이브 데스크톱 앱 폴더 읽기 등 선택 기능은 사용자가 켠 경우에만, 사용자 PC 안에서 동작합니다.

4. Google API 사용자 데이터 정책

앱이 Google API 에서 받은 정보를 사용하고 다른 앱으로 전송하는 것은 Google API 서비스 사용자 데이터 정책(제한된 사용 요건 포함)을 따릅니다.

5. 삭제와 권한 해제

  • 앱의 사이드바 ‘로그아웃’으로 로그인 쿠키를 지울 수 있습니다. 앱과 앱 폴더를 지우면 모든 기록이 사라집니다.
  • Google 계정의 타사 앱 액세스에서 언제든 마에스트로의 권한을 해제할 수 있습니다.
